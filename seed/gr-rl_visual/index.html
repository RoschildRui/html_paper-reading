GR-RL：用强化学习把「通用机器人大脑」打磨成会系鞋带的专家

GR-RL: Going Dexterous and Precise for Long-Horizon Robotic Manipulation

arXiv preprint · 2025.12 ByteDance Seed cs.RO / cs.LG arXiv:2512.01801（v1 12-01 / v3 12-23） 5B 参数 · VLA + Critic

一句话：通用的视觉-语言-动作（VLA）模型很「博学」，却不够「可靠」。GR-RL 不再假设人类示范是最优的，而是用一条 过滤 → 增强 → 在线强化 的三段式流水线，把通用策略 GR-3 打磨成一个能自主把鞋带穿过多个鞋孔、成功率 83.3% 的灵巧操作专家。

本页基于已抓取的 arXiv 全文（v3，2025.12.23）正文与三张原始方法图构建。术语首次出现时给出英文原词，便于对照原文；项目主页：seed.bytedance.com/gr_rl ↗。

00 TL;DR · 30 秒抓住核心

  • 核心痛点：在毫米级精度 + 长程 + 灵巧的任务里（如系鞋带），人类示范本身就是带噪声、次优的——人会犹豫、出错、动作前后不一致。直接行为克隆（BC）只会把这些坏习惯一起学进去。
  • 三步打磨流水线：① 数据过滤——用离线 RL 学一个"任务进度评估器"，剔除掉示范里拖后腿的片段；② 形态对称增强——利用双臂任务的左右镜像对称扩充数据；③ 在线 steering RL——让模型在真机闭环里试错，弥补"训练动作"与"部署动作"的错位。
  • 关键技巧：把稀疏奖励下学到的 Q 值当作任务进度（分布式 critic，输出有界 0~1）；在线探索不加动作噪声，而是在隐空间里预测初始噪声来 steering flow 策略。
  • 结果：成功率从 GR-3 基线 45.7% → 61.6%（过滤）→ 72.7%（增强）→ 83.3%（在线），在线阶段峰值一度超过 90%。这是已知首个能自动系鞋带的学习型策略。
「现有 VLA 策略的核心假设是『人类示范是最优的』。但我们主张：在高度灵巧、高精度的操作任务里，人类示范是带噪声、次优的。」
—— 论文摘要（释义自 “we claim that … human demonstrations are noisy and suboptimal”）

01 问题：通用 ≠ 可靠

大规模 VLA 模型让「通用机器人」成为可能：给一张图、一句自然语言指令，模型就能泛化到很多物体、场景和语义概念。但论文一针见血地指出——「能做很多事」不等于「每件事都做得可靠」。面向真实部署，当前 VLA 还卡在两个根本问题上：

  • 灵巧 + 精度（Dexterity with precision）：对可变形物体的毫米级控制仍未解决。
  • 长程鲁棒性（Long-horizon robustness）：误差会逐步累积，当它和高精度灵巧操作叠加时会更糟。
贯穿全文的 motivating example：系鞋带（shoe lacing）
这一个任务同时压满了三种难度：（1）要足够灵巧，才能同时操控鞋带和鞋这两个可变形物体；（2）要毫米级精度，才能把鞋带穿进鞋孔（eyelet）；（3）要长程能力，才能应对各种意外（鞋带掉了、穿歪了、抓得太浅……）。经典方法靠运动规划 + 预设动作原语来系鞋带，泛化和失败恢复都成问题；而朴素地套用行为克隆，只能得到次优、能力受限的策略。

为什么从 GR-3 出发还会失败？两个瓶颈

GR-RL 的起点是 GR-3——一个用互联网数据、机器人轨迹和人类示范联合训练的大规模 VLA 策略。它泛化很强，但一旦遇到「要精度、要灵巧、要长程」的场景就会掉链子。论文把原因归结为两点：

瓶颈一：示范本身次优
  • 在极端精细的场景里，遥操作者会放慢、犹豫，给策略灌进噪声、次优的轨迹
  • 就算是熟练遥操作员的数据，也含误操作、迟疑等次优片段
  • 人工标注哪些片段「不好」既费力，又会引入更主观的噪声
瓶颈二：训练-推理错位
  • 训练时策略学的是滑窗切出的定长动作块（action chunk）
  • 但部署时为了平滑执行，会叠加时序集成（temporal ensembling）、receding horizon 控制等后处理
  • 结果：训练见到的动作 ≠ 部署真正执行的动作，在高精度任务里这个错位不可忽视

02 已有方案卡在哪

论文没有堆砌相关工作，而是聚焦几条与 GR-RL 形成对比的技术路线。理解它们的「卡点」，就能明白 GR-RL 为什么选择「真机离线 + 在线 RL」这条路。

📐运动规划 + 预设原语 经典法
用预先设计好的动作原语和固定模式，靠运动规划完成系鞋带等任务。
展开说明 ▸

做法：把任务拆成人工设计的 primitive（抓、穿、拉……），用 motion planning 串起来执行。

卡在哪：高度依赖人工脚本，泛化到没见过的配置、从失败中恢复、以及其它灵巧技能都成了悬而未决的问题。

与本文关系：GR-RL 要的是学习型、可泛化、能自我纠错的策略，而非写死的流程。

🧬朴素行为克隆 / GR-3 本文底座
大规模 VLA 直接模仿人类示范，假设示范即最优。
展开说明 ▸

做法：把"问题→人类动作"当监督信号，让 VLA（如 GR-3）模仿全部遥操作数据。

卡在哪：示范带噪声、次优，BC 会把坏习惯一起学进去；且能力上界被示范锁死，无法超越示范者，还易受复合误差（compounding errors）影响。

与本文关系：GR-RL 直接反对"示范最优"假设，先过滤再强化，正是为了突破 BC 的天花板。

🕹️仿真里做在线 RL Sim RL
在模拟器里对 VLA 做 on-policy RL，再迁移到真机。
展开说明 ▸

做法：用仿真的廉价交互做策略提升，规避真机采样昂贵的问题。

卡在哪：真机交互样本低效、含噪声，仿真到现实的迁移仍然很难，尤其在可变形物体、毫米级精度场景。

与本文关系：GR-RL 选择直接在真机做 off-policy RL，复用历史轨迹来提升样本效率。

🌐世界模型 RL World Model
学一个世界模型，让策略在"想象"的环境里做 on-policy RL。
展开说明 ▸

做法：用学到的世界模型预测未来，缓解真机交互成本。

卡在哪：视觉预测不准确会引入新的误差来源，在精细操作中尤其致命。

与本文关系：GR-RL 不依赖想象，把分布式 critic 用在真实奖励上，并指出与同期工作 π*₀.₆ 都用分布式 critic 学进度，但 GR-RL 走的是过滤式 BC 而非 advantage-conditioned denoising。

03 方法总览：过滤 → 增强 → 在线，三步打磨

04 模型：一套 VLM 骨干，挂两个头

GR-RL 采用 Mixture-of-Transformer（MoT） 架构，由一个 VLA 策略 πθ 和一个多任务评论家 Qφ 组成，总计 5B 参数。两者共享同一个视觉-语言骨干，各自挂一个下游 Transformer：一个产动作，一个评进度。

图 2（原论文 Figure 2）：GR-RL 模型。共享 VLM 骨干同时驱动「动作扩散 Transformer（flow matching）」与「Critic Transformer（分布式 RL / TD 误差）」。
展开说明 ▸
  • 左侧 Vision-Language Model（Qwen2.5-VL-3B-Instruct）：输入系统提示、head/left/right 三路摄像头图像，以及自然语言指令（如 “thread the shoelace through …”），编码成共享表征。
  • 中间 kv cache 箭头：只取 VLM 后半段层的 KV 缓存喂给两个下游头，兼顾表达力与推理速度（沿用 GR-3 的快速推理设计）。
  • 右上 Action Diffusion Transformer（动作 DiT）：以 proprios（本体感知）+ noisy actions 为输入，用 flow matching 去噪生成定长动作块——这是「策略」。
  • 右下 Critic Transformer：以 proprios + actions 为输入，输出 value predictions（红色）——这是「评论家」，与策略共享骨干构成 MoT。
  • 最右分布式细节：critic 不回归单个标量，而是输出一个有界（0~1）的离散值分布，用 cross entropy 对齐 target value distribution；这让稀疏奖励下的进度估计更稳健。

一句话：一套 VLM 骨干 + 两个头——flow matching 产动作，distributional RL 评进度。

🎮 策略 Policy · πθ
  • 控制带移动底盘的双臂机器人，给定指令 l、观测 ot、状态 st，生成长度为 k 的动作块 at=at:t+k
  • VLM 骨干用 Qwen2.5-VL-3B-Instruct
  • 动作由 action DiT 预测，训练目标是 flow matching
⚖️ 评论家 Critic · Qφ
  • 因果 Transformer，对每个动作块预测一串 Q 值（沿用 Q-chunking）
  • 采用分布式 RL：把价值视为有上下界的离散分布，天然刻画真实轨迹的不确定性
  • 上界设 1、下界设 0，Q 值即任务进度；稀疏奖励下比非分布式 critic 稳得多

05 阶段一：把「Q 值」当成任务进度计

高精度可变形物体操作（如系鞋带），采集完美示范几乎不可能——再熟练的遥操作员也会留下误操作、犹豫等次优片段。直接全盘模仿，会把这些噪声多模态动作灌进训练。但人工去标注"哪段不好"，又会引入更主观的噪声。GR-RL 的巧思是：让 RL 自己学出一把"进度尺"。

怎么把稀疏奖励变成进度函数

  • 训练 critic（TD3+BC）：奖励是稀疏的——只在轨迹成功结束时给 +1，其余为 0。
  • 人为制造失败样本：由于大多数轨迹都成功，论文标注每条示范里的"重试关键帧"，用 hindsight 的方式在这些关键帧处截断出多条失败轨迹。这样成功 + 失败数据都有，TD 学习才能学出可靠的进度。
  • 读出进度 ρ：对每个 transition，取分布式 critic 类别分布的均值作为进度 ρ。
  • 定义并剔除次优：若一段窗口 ρt:t+k 内进度下跌超过阈值 δ，就判定该样本次优、从训练集中删除。剩下的"干净"数据，用普通 BC 训 πθ 即可。
rt = 𝕀(τ 成功) · γ(T−t)   ⟶   ρt = mean( Qφ 的类别分布 )
稀疏奖励只在结尾给信号；经 TD 学习后，每一步的 Q 值就成了"离成功还有多远"的连续进度 ρ。

一句话：分布式 critic 既能在失误处掉头、又懂得为长远收益打分，正好当数据过滤的"裁判"。

06 阶段二：用「左右镜像」免费造数据

在离线训练阶段，GR-RL 用了一招简单却有效的形态对称增强（morphological symmetry augmentation）。它利用了双臂任务里天然存在的左右镜像对称：同一个系鞋带动作，镜像翻转后仍是一个物理上合理的系鞋带动作。

  • 图像：全部水平翻转，再把左手腕视角与右手腕视角互换。
  • 本体状态 st 与动作 at：先在世界坐标系做镜像变换，再转回各自的腕部局部坐标系。
  • 语言指令：相应翻转空间描述，例如把"左边的孔"改成"右边的孔"。
效果
仅靠这一镜像增强，过滤后 BC 策略的成功率就从 61.6% 提升到 72.7%，并明显增强泛化能力——几乎零成本地把数据量翻倍，还顺带让模型"左右都会做"。

07 阶段三：在隐空间里做在线强化

部署时为了让机器人动作平滑，常要叠加时序集成、receding horizon 控制等后处理。但这造成了训练-部署错位：训练时模型见的是原始动作，部署时执行的是被优化过的动作。在灵巧高精度任务里，这个错位不可忽视。解法只有一个——让模型在真机闭环里、用"对齐后的动作"亲自试错。

难点：毫米级任务不能靠"加噪声"探索

长程高精度任务的在线 RL，最难的是探索。任务要毫米级精度才能完成，直接给腕部位姿或关节加噪声，几乎不可能探索到成功。GR-RL 改在隐空间做结构化探索：

NOISE PREDICTOR
隐空间噪声预测器 πθ′
在共享 VLM 骨干后接一个噪声预测器，为 action DiT 预测初始噪声 εt，以此 steering flow 策略走向高回报区域。可训练参数仅 51.5M。
只动一小部分参数
STAY IN-DISTRIBUTION
约束在分布内
当预测噪声偏离原始正态分布超过阈值 β 时施加惩罚，避免从噪声生成离线分布之外的乱动作。
不跑出离线分布
NOISE-SPACE Q
隐空间 Qφ′
蒸馏一个噪声空间的 Q 函数，避免优化时反传穿过 flow 模型；动作空间的 Qφ 用标准 TD3 训练。蒸馏时以 0.5 概率从正态采样、否则用预测器采样，保证噪声空间覆盖。
绕开 flow 反传
样本高效的离线→在线衔接
维护离线 buffer + 在线 buffer，各采一半。开训前先用离线 checkpoint 的在线 rollout 预热离线 buffer（类似 Warm-start RL）。刻意不混入遥操作轨迹，以免在"错位动力学"上训练。在线 buffer 只存最近两个 checkpoint 的轨迹，过期数据下放到离线 buffer。

训练细节：先采 673 条离线模型 rollout，冻结 VLM 骨干、只续训 critic 头以对齐 rollout 分布；每收集 12 条新在线 episode，就对噪声预测器和两个 critic 头做 50 步优化；成功率移动平均窗口为 24。早期因离线→在线分布漂移会先掉，随后迅速恢复并涨过离线水平、超过 90%；取第 500 个在线步的 checkpoint 评测，得到 83.3%。

08 硬件：ByteMini-v2 机器人

验证 GR-RL 的本体是 ByteMini-v2——一台带移动底盘的双 7-DoF 机械臂机器人，腕部为独特的球形关节设计。相比在 GR-3 中验证过的 v1，v2 针对实测痛点做了三处升级：

💪更大负载
肘部执行器峰值扭矩 17 → 35 Nm，单臂峰值负载 1.4 → 3.15 kg，操作能力显著扩展。
🛞狭窄空间更灵活
底盘投影 500×720 → 450×650 mm；舵轮可在偏航/俯仰方向同步调整，提升狭小空间里的快速转向能力。
✨更精致、更好用
外露线束做了 ID 与封装；便携显示屏从底盘移到肩部，使用体验更好。

09 有意思的点

除了主线，这几处设计取舍往往比 benchmark 数字更能帮你判断这套方法适不适合自己的场景。

📊分布式 critic 完胜回归 critic
同样 TD3+BC，回归 critic 严重高估、值域无界；分布式 critic 落在 0~1，进度更靠谱。
展开说明 ▸

长程 + 二值稀疏奖励下，非分布式 critic 严重过估，尤其在轨迹早期奖励信号弱的地方（见原论文 Fig. 7）。

分布式 critic 把价值限定在预设区间，收敛到合理尺度更稳健，与真实时间顺序对齐得更好——这是进度评估器能用的前提。

🎚️不加动作噪声，改在隐空间探索
毫米级任务一加动作噪声就失败，改为隐空间预测初始噪声去 steering。
展开说明 ▸

对腕部位姿/关节加噪声几乎探索不到成功；GR-RL 在隐空间学一个轻量噪声预测器（51.5M）steering flow 策略。

启发：当动作空间对精度极敏感时，把探索"挪到"表征/噪声空间，比直接扰动动作更安全有效。

🔁用 hindsight 主动造失败
成功轨迹太多、缺负样本？在"重试关键帧"处截断，造出失败轨迹。
展开说明 ▸

稀疏奖励 + 几乎全成功的数据，会让 critic 学不到"什么是失败"。论文标注重试关键帧 mi，把成功轨迹 τ0:T 截成多条失败轨迹 τ0:mi。

成功/失败兼备后，TD 学习才能让 Q 值真正反映进度涨落。

🦾对失败的"自发"鲁棒行为
掉了会重抓、穿歪了会重试、还会主动调整场景让任务更好做。
展开说明 ▸

原论文 Fig. 8 展示：换不同颜色/尺寸的鞋都能做；鞋带掉落或没穿进孔会自动重试。

更妙的是会主动改造场景：抓得太浅就把鞋带放到鞋面上重抓近鞋带尖端；鞋摆歪了先扶正；鞋太远先拉近；两端交叉时能挑出该抓的那一根。

11 局限与结论

论文坦诚地列出了当前 GR-RL 的短板：

  • 行为漂移（behavior-drifting）：稀疏且带噪的奖励下，在线 RL 时策略行为可能不稳定。可能原因是轻量噪声预测器容量有限，或大隐动作空间里的信用分配（credit assignment）难题。
  • 尚未回灌基座：把提升后的专家策略蒸馏回基础 VLA，以同时获得"通用 + 能干"的策略，是个有前景但留待未来的方向。
这篇论文最值得记住的一句话
GR-RL 的核心洞见是：数据采集与策略推理之间的错位，需要靠在线对齐来弥补。把稀疏奖励学到的 critic 值当作任务进度去过滤数据、再用形态对称增强、最后用在线 RL 把 rollout 行为与训练信号对齐——三步就把一个通用 VLA 特化成了已知首个会系鞋带的专家。
