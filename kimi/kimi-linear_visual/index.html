Kimi Linear：第一次，混合线性注意力又快又强地「超过」了全注意力

Kimi Linear: An Expressive, Efficient Attention Architecture

arXiv 预印本 · Technical Report 发表 2025.10（v1 10.30 / v2 11.01） Moonshot AI · Kimi Team 48B 总参 / 3B 激活（MoE） arXiv:2510.26692

一句话：把廉价的线性注意力（固定大小记忆、随长度线性增长的成本）做得足够「聪明」，再用少量全注意力兜底，最终在短上下文、长上下文、RL 后训练三种场景下，都同时赢了质量和效率——这在过去的混合架构里是没做到过的。

核心是 Kimi Delta Attention（KDA）：给 Gated DeltaNet 换上按通道的细粒度遗忘门，并用一个受约束的 DPLR 形式把它做到硬件高效。下文术语首次出现时附英文原词，方便对照原文。本页所有原始图均取自论文 PDF（无 arXiv HTML 版，由 PDF 高清渲染裁剪）。

00 TL;DR · 30 秒抓住核心

  • 问题：当大模型变成「智能体」、要做长链推理与 RL 测试时扩展（RL test-time scaling）时，标准 softmax 注意力的二次方计算与线性增长的 KV 缓存成了瓶颈。
  • 做法：提出 KDA（Kimi Delta Attention）——在 Gated DeltaNet 的基础上，把整头共用一个标量遗忘门换成每个通道独立的细粒度门，从而更精细地利用有限的 RNN 状态记忆。
  • 跑得快：KDA 用一个受约束的 DPLR（对角 + 低秩）形式，配合定制的分块并行算法，内核速度比通用 DPLR 快约 2×。
  • 组装：按 3:1 的比例交错堆叠「3 层 KDA + 1 层全注意力（MLA）」，并对 MLA 层用 NoPE（不加位置编码）。48B 总参 / 3B 激活的 MoE 模型，1.4T token 公平对比。
  • 结果：同一训练配方下，全面优于全注意力 MLA；KV 缓存最多省 75%，1M 上下文解码吞吐最高 6×。

01 问题：为什么标准注意力撑不住「长 + 多」的未来

大模型正在变成需要长时间自主行动的智能体（agent）：要处理超长轨迹、反复调用工具、在推理时反复「想更久」（即 RL 测试时扩展）。这把标准 softmax 注意力的两个老问题彻底放大了：

  • 二次方计算（quadratic time）：注意力要算一张 T×T 的相似度矩阵，序列越长，计算量增长得越快。
  • KV 缓存线性膨胀：每生成一个 token，都要把所有历史 key/value 留在显存里。上下文到百万级时，显存与带宽成了硬约束，拖慢吞吐、限制批大小、伤害实时交互。
全注意力（Softmax / MLA）
  • 计算复杂度 O(T²)，长序列代价高
  • KV 缓存随长度线性增长，永不丢弃
  • 能精确检索任意历史 token（这是它的强项）
线性注意力（Linear Attention）
  • 把历史压进固定大小的状态矩阵 S
  • 计算与显存随长度线性 / 常数增长
  • 代价：有限状态记忆 → 精确检索 / 复制天然吃亏
本文要回答的核心问题
能不能造一个注意力架构，在质量上追平甚至超过全注意力，同时在速度和显存上拿到线性注意力级别的巨大收益？过去的混合架构要么规模太小、要么评测不全， 没有真正同时做到。

02 已有方案卡在哪

Kimi Linear 不是凭空冒出来的，它站在一条清晰的演进链上。理解这几条路线「各自强在哪、卡在哪」，才能看懂 KDA 为什么这样设计。下面四张卡片按从弱到强排列：

📐线性注意力 起点, 2020
用一个固定大小的状态矩阵累加 key-value 关联，把 O(T²) 降到线性。
展开说明 ▸

做法：维护状态 S_t = S_{t-1} + k_t v_tᵀ，输出 o_t = S_tᵀ q_t。从「快权重 / 在线学习」视角看，S 是一张随时间更新的联想记忆表。

卡在哪：这等于在做一个只奖励、不遗忘的目标——旧关联永远累加，状态被无关信息撑爆，长上下文里互相干扰。表达力明显弱于 softmax。

与本文关系：所有后续改进（含 KDA）都是在给这个朴素累加加上「该忘什么、该纠正什么」的判据。

🚪门控 / 衰减 RetNet · Mamba2 · GLA
给状态加一个遗忘门（forget gate），让旧记忆按比例衰减。
展开说明 ▸

做法：在递推里乘一个衰减因子 α。RetNet 用固定标量衰减；Mamba2 用数据相关的标量衰减；GLA 进一步用按通道的对角门 Diag(α_t)，每个特征维度有自己的遗忘率。

卡在哪：衰减能控制记忆寿命、缓解干扰，但缺少「主动纠错」——它只会按比例淡忘，不会针对性地覆盖写入冲突的旧关联，精确检索仍偏弱。

与本文关系：KDA 的细粒度通道门正是借鉴了 GLA 这一路的「per-channel 衰减」。

✏️Delta 规则 DeltaNet · GDN
把记忆更新看作对「重构损失」做一步梯度下降，主动纠正旧关联。
展开说明 ▸

做法：DeltaNet 把更新写成 S_t = (I − β_t k_t k_tᵀ) S_{t-1} + β_t k_t v_tᵀ，相当于让记忆朝「k→v 的正确映射」自我修正（rank-1 更新，可分块并行）。Gated DeltaNet（GDN）再叠加一个标量遗忘门。

卡在哪：GDN 的遗忘门是整头共用一个标量（head-wise scalar），无法对不同特征维度区别对待——这正是 KDA 要改的地方。

与本文关系：KDA = GDN + 把标量门换成按通道的对角门。这是本文最核心的一步。

🧩混合架构 Jamba · MiniMax · …
大部分用快的线性层，穿插少量全注意力层兜底全局检索。
展开说明 ▸

做法：纯线性注意力在「精确复制 / 极长检索」上始终偏弱，于是把线性层与少量全注意力层交错堆叠，兼顾效率与质量。

卡在哪：之前的混合模型要么规模有限、要么评测不全面，没能在公平对比下证明「混合能稳稳超过全注意力」。

与本文关系：Kimi Linear 用层间（inter-layer）3:1 混合 + KDA + NoPE，并在 1.4T token 规模做公平验证，第一次把这件事坐实。

下面一节先用一个分步演示，把「线性注意力 → DeltaNet → GDN → KDA」这条演进链走一遍，你就能直观看到 KDA 到底改了什么。

03 核心思路：三件事拼成 Kimi Linear

论文把贡献明确拆成三块，正好对应「算子怎么设计 → 怎么拼成模型 → 怎么证明它真的好」三个层次：

① 算子
KDA 细粒度门控
在 gated delta rule 上引入按通道的对角遗忘门，让有限状态记忆被更精确地管理；并保持可分块并行、硬件高效。
② 架构
3:1 层间混合
3 层 KDA 配 1 层全注意力（MLA），MLA 层用 NoPE。在大幅降显存的同时，靠少量全局层保住全局信息流。
③ 验证
公平的大规模实验
1.4T token 训练，在短 / 长上下文 + RL 三类场景全面对比全注意力与其它基线，并开源内核、vLLM 集成与权重。
一句话串起来
KDA 是发动机（让线性注意力变聪明），3:1 混合 + NoPE 是底盘（拼成可用的大模型），大规模公平实验是路测（证明又快又强）。接下来按这三层依次展开。

05 KDA：细粒度门控为什么更「expressive」

KDA 的全称是 Kimi Delta Attention。它和 GDN 只差一个改动，但这个改动直击线性注意力的命门——有限状态记忆的利用率。核心对比就在「遗忘门的粒度」：

GDN / Mamba2 · head-wise 标量门
  • 整个注意力头共用一个遗忘率 α_t
  • 所有特征维度被「一刀切」地同速衰减
  • 无法对「重要维度多记、噪声维度快忘」做区分
KDA · channel-wise 对角门
  • 每个特征维度有独立遗忘率 Diag(α_t)
  • 记忆寿命可以逐通道精细调节
  • 有限的 RNN 状态被更充分地利用 → 检索 / 复制更准
S_t = (I − β_t k_t k_tᵀ) Diag(α_t) S_{t-1} + β_t k_t v_tᵀ
KDA 的递推：Diag(α_t) 是按通道的细粒度衰减（红色高亮项），(I − β_t k_t k_tᵀ) 是 delta 规则的擦除-重写。两者结合 = 既能精细遗忘、又能主动纠错。

论文还给了一个很漂亮的视角：这种数据相关、可学习的衰减，本质上是一种「学出来的位置编码」。RoPE 用固定频率的旋转矩阵给不同维度注入位置信息；KDA 的 Diag(α_t) 则是数据相关、逐通道的乘性变换，放松了 RoPE 的正交约束，理论上更灵活——这也是为什么 Kimi Linear 敢对全注意力层「不加任何位置编码（NoPE）」，把位置感知的活儿全交给 KDA（详见「有意思的点」）。

神经参数化：KDA 块里还藏着哪些组件

真正落地时，q/k/v 不是直接喂进去的。KDA 在输入侧和输出侧都加了若干轻量组件来提升表达力与稳定性：

  • ShortConv + Swish：对 q、k、v 先做一个短卷积捕捉局部依赖，再过 Swish 激活。
  • L2Norm（仅 q、k）：归一化以稳定特征值，避免递推发散。
  • 低秩门：按通道遗忘门 α_t 与输出门都用低秩投影（rank = head dim）参数化，控制参数量、便于公平对比。
  • head-wise RMSNorm + Sigmoid 输出门：在输出投影前做归一化与数据相关门控，缓解「注意力沉降（attention sink）」。

06 让它跑得快：受约束的 DPLR + 分块并行

细粒度门控好是好，但有个隐患：表达力越强，往往越难算得快。KDA 在表达力上等价于更一般的 DPLR（Diagonal-Plus-Low-Rank，对角 + 低秩）形式 S_t = (D − a_t b_tᵀ)S_{t-1} + k_t v_tᵀ，但通用 DPLR 计算昂贵、难并行。KDA 的高效，来自一个聪明的约束。

关键技巧：把 a、b 都绑定到 k
在通用 DPLR 里，a_t 和 b_t 是两个独立向量。KDA 强制令 a_t = β_t k_t、b_t = k_t ⊙ α_t，即都由 k_t 派生。这看似只是个约束，却让 KDA 既保持了 DPLR 级别的细粒度衰减，又更贴近经典 delta 规则、还大幅省掉了冗余计算。

这个约束带来两处实打实的提速（对照论文的 DPLR vs KDA 伪代码）：

  • 少两次二级分块（secondary chunking）：通用 DPLR 在分块输出里要除以累积衰减 1/Γ，会有数值不稳定，得靠全精度二级分块来救；KDA 通过 a=b=k 的约束直接免掉这两步，不再需要额外的 I/O 与计算。
  • 少约三次矩阵乘：在 inter-chunk 与输出计算阶段，KDA 进一步消掉了约 3 个矩阵乘法，带来内核级加速。

一句话总结：KDA 用一个「a=b=k」的约束，在几乎不损失表达力的前提下把内核做到了约 2× 的速度。

o = (q*g.exp())@S + Aqk@(u−w@S)
S = S * g_last.exp()
S += (k*decay)ᵀ @ v
# 无需第二条 S 更新

对照可见：DPLR 维护 4 个交互矩阵、两条状态更新；KDA 因为 a=b=k 只需 2 个交互矩阵、一条状态更新，输出也合并成一行——这就是约 2× 加速的来源。（伪代码改写自论文 Listing。）

训练 / 推理两套内核 + 固定大小状态

  • 预填充（prefill）用 FLOP 密集的分块内核，吃满 Tensor Core；自回归解码切换到更省的递归内核。
  • KDA 的状态恒为 d_k×d_v（128×128），与序列长度无关——这正是 KV 缓存能省到 75%、解码能快数倍的根本原因。

07 Kimi Linear 架构：3 层 KDA + 1 层 MLA 的混合塔

有了高效的 KDA 算子，剩下的问题是怎么拼成一个能打的大模型。Kimi Linear 的骨架沿用 Moonlight，每个 block = 一层「token 混合」+ 一层「MoE 通道混合」。关键在于 token 混合层按 3:1 交错使用 KDA 与全注意力。这张架构图是全文最重要的一张：

图 3（原论文 Figure 3）：Kimi Linear 整体架构。左侧是层间混合的堆叠方式（N 个 KDA block + 1 个 MLA block，N=3）；右上是 MoE 通道混合层（共享专家 + 路由专家）；右下是 KDA token 混合模块的内部结构。
展开说明 ▸
  • 左侧整体堆叠：模型由两种 block 交错堆成。下方标注 N× 的是 KDA block（Norm → KDA → 残差，再 Norm → MoE → 残差）；上方标注 1× 的是 MLA block（把 KDA 换成全注意力 MLA）。每 3 个 KDA block 配 1 个 MLA block，即 3:1。
  • 为什么是层间（layerwise）而非头间（headwise）：整层切换比「层内混头」基础设施更简单、训练更稳，KV 缓存管理也更规整。
  • 右上 MoE 层：通道混合用专家混合（Mixture-of-Experts）。绿色是共享专家（Shared Expert）（每个 token 都过），蓝色是路由专家（Routed Expert），由下方 Router 按打分稀疏选取（图中柱状即路由权重，⊗ 表示按权重缩放）。本文配置为 256 选 8 + 1 共享，48B 总参 / 3B 激活。
  • 右下 KDA 模块内部：输入分别经过 Linear → Conv（ShortConv） 得到 q、k；q/k 还要过 L2 归一化；几路梯形是低秩投影，σ 表示 sigmoid 门（生成遗忘门 α、写入强度 β、输出门）。这些汇入中间的 Kimi Delta Attention，输出再过 Norm 与输出门（⊗），最后 Linear 投影回主干。
  • 数据流主线：每个 block 都是「归一化 → 混合算子 → 残差相加」的标准结构；竖直主干就是 token 表示一路向上流动、被 KDA / MLA / MoE 逐层精炼。
  • NoPE：所有 MLA（全注意力）层都不加位置编码，位置信息完全交给 KDA 层承担（见下一节）。

一句话总结：大部分层用便宜的 KDA 扛主力，少数 MLA 层负责全局精确检索，MoE 负责扩容量——三者按固定节奏堆叠，既省显存又保质量。

为什么 3:1 是「甜点比例」

论文专门做了混合比例的消融，结论很干净：

  • 3:1 最优：训练与验证 loss 都最低。
  • 7:1（更多 KDA）：训练 loss 接近，但验证明显变差——全局层太少，泛化受损。
  • 1:1（更多全注意力）：验证相当，但推理开销大增，得不偿失。
  • 0:1（纯全注意力）：表现最差——印证了「适度混入线性层反而更好」。

08 有意思的点

除了主线，有几处设计取舍值得单独拎出来——它们解释了 Kimi Linear 一些「反直觉」的选择。

🧭KDA = 学出来的位置编码
数据相关的细粒度衰减，可被看作比 RoPE 更灵活的乘性位置编码。
展开说明 ▸

RoPE 用固定频率的旋转矩阵给每对维度注入相对位置；而 gated delta rule 的累积转移矩阵是数据相关、可学习的，相当于放松了 RoPE 的正交约束，理论上更强。

RoPE 的固定频率还会导致外推（extrapolation）困难（容易过拟合到训练时见过的长度）。把位置感知交给可学习的 KDA，反而更容易扩展上下文窗口。

🚫全注意力层干脆 NoPE
既然 KDA 已经在编码位置，MLA 层就不再加任何位置编码。
展开说明 ▸

Kimi Linear 把位置感知的责任全部委托给 KDA 层，MLA 全注意力层用 NoPE。好处有二：① 推理时 MLA 可转成高效的纯 MQA（多查询注意力）；② 长上下文训练更简单，不用调 RoPE 频率基或上 YaRN。

消融显示：Kimi Linear（NoPE）在长上下文上稳定胜过 RoPE 版，因为位置偏置在各层间分布得更均衡，外推更鲁棒。

🎚️输出门：Sigmoid 完胜 Swish
一个小小的门控激活选择，对最终质量影响不小。
展开说明 ▸

消融对比了「无门 / Swish 门 / Sigmoid 门」三种输出门：去掉门会掉点；GDN 采用的 Swish 门明显差于 Sigmoid。本文因此全程用 Sigmoid 输出门（含 GDN-H 基线），还能缓解注意力沉降。

启发：在这类线性注意力里，输出门的设计不是细枝末节，值得认真消融。

⚖️线性 vs 稀疏：两条不同的路
论文专门讨论了线性注意力与稀疏注意力的本质区别。
展开说明 ▸

稀疏注意力（NSA / MoBA / DSA 等）擅长精确检索细粒度历史，但仍要存整份 KV 缓存来做 token 选择，表达上界也只是全注意力。

线性注意力秉持「压缩即智能」，用固定大小状态泛化，配合 delta 规则可获得理论上更强的表达力；弱在检索，但能用状态扩展等手段弥补。

言下之意：两者并不互斥，未来可结合「线性的压缩 + 稀疏的精检」。

一句话总结：合成任务证明 KDA 的细粒度门控不是纸面优化，而是真的提升了有限状态记忆的检索能力。

10 适用边界与展望

论文整体是一份「捷报」，但它也诚实地交代了线性注意力路线的内在权衡与未尽之处——这些往往比成绩单更能帮你判断它适不适合你的场景：

  • 纯线性注意力仍有检索短板：精确复制、超长检索是固定状态记忆的天然弱项，所以 Kimi Linear 必须靠少量全注意力层兜底（这也是「混合」而非「纯线性」的原因）。
  • 依赖底层基础设施：线性注意力长期受限于硬件实现与推理基建。本文专门开源了 KDA 内核与 vLLM 集成来补这一环，但这也说明没有好内核，理论收益难落地。
  • 稀疏注意力是互补而非对手：稀疏注意力在精检上更强但要存全量 KV。作者认为未来可把「线性的压缩泛化 + 稀疏的精细检索」结合，进一步提升。
这篇报告最值得记住的一句话
只要把线性注意力的记忆管理（细粒度门控 + delta 纠错）和硬件效率（受约束 DPLR）同时做扎实，再用少量全注意力兜底，混合架构就能第一次在公平对比下，同时赢下质量与效率——并成为全注意力的直接替换。
