On-Policy Distillation · 在线策略蒸馏

不是每个 token 都值得学：
OPD 的「位置偏差」与 IW-OPD

arXiv preprint 2026.06（v3：2026-06-26） cs.LG / cs.AI arXiv:2606.22600

Yan Xie, Sijie Zhu, Tiansheng Wen, Bo Chen, Yifei Wang · 西安电子科技大学 / Georgia Tech / Amazon AGI SF Lab

在线策略蒸馏（OPD）让小学生模型在自己生成的轨迹上，接受更强教师的逐 token 监督，比稀疏的轨迹级奖励学得更快。但标准 OPD 把每个 token 的损失「一视同仁」地平均——本文发现这恰恰是它的低效之处。

TL;DR · 30 秒抓住核心

学生越往后生成，轨迹越偏离教师的「推理偏好路径」，后段 token 上的教师监督越不可信。这导致 OPD 存在一个明显的 位置偏差（Position Bias）： 只用前 30% 的 token 训练，效果≈用全部 token；只用后 30% 的 token，几乎学不到东西。

作者用「有限预算分配 / 信赖域受限优化」的视角解释了这个现象：在每步只能小步更新的约束下，最优策略会按教师/学生的似然比给 token 重新加权，自然地上调早期 token、下调漂移后的晚期 token。 据此提出 IW-OPD（重要性加权在线策略蒸馏）：用一个稳定的「累计前缀差异」权重，把梯度预算重新分配给教师兼容的前缀，同时保留标准 OPD 作为稠密监督的底座。

背景

OPD 是什么，为什么需要它

后训练（post-training）阶段，大模型常用 RLVR（带可验证奖励的强化学习，如 GRPO）来提升推理能力。但 RLVR 的奖励是稀疏的：一整条几千 token 的推理轨迹，最后只得到一个「对/错」的标量奖励，每个 token 分到的信用都一样，学习信号非常弱。

在线策略蒸馏（OPD）换了一种监督来源：让学生在自己生成的轨迹上跑，由一个更强的教师模型在学生走过的每一个前缀上，给出逐 token 的稠密监督（最小化学生与教师的逐 token KL 散度）。信号从「一条一个奖励」变成「每个 token 一个目标」，学习效率大幅提升。

RLVR / 稀疏奖励

一条轨迹，一个标量

整条轨迹结束后只有一个 reward r(x,y)，优势 A_t 对每个 token 都相同 → 信用分配粗糙、样本效率低。

OPD / 稠密监督

每个 token，一个教师目标

教师在每个前缀上给出分布，逐 token 计算 KL；优势来自教师–学生分布差，监督密集得多。

标准 OPD 的目标，本质是在学生采样的轨迹上最小化逐 token 的反向 KL：

JOPD(θ) = maxθ  −DKL(πθ ‖ πT) = −Ey∼πθ ∑t=1..T log( πθ(yt|y<t) / πT(yt|y<t) ) Eq.4

实践中它写成策略梯度形式，每个 token 的「优势」就是教师与学生的对数概率差：

AtOPD = −( log πθ(yt|y<t) − log πT(yt|y<t) ) = log πT − log πθ Eq.6

问题就藏在 Eq.4 的那个求和里：它把所有位置的 token 损失均匀平均，默认每个 token 都同样可靠。但 OPD 的样本是弱学生生成的，经常产出对教师而言「分布外（OOD）」的内容——这个假设站不住脚。

核心发现

OPD 的位置偏差现象

作者用两个干净的对照实验，揭示了「不是每个 token 都平等」。

现象一：OPD 的收益主要来自早期 token

现象二：训练后教师–学生差距大体仍在

即便 OPD 的目标就是缩小师生 KL，实际 KL 只下降了约 20% 就停住了，即使学生性能已经饱和。这说明 OPD 只能在一个很小的局部范围内移动学生分布——这类「在自己样本上做 RL」的训练，本来就以权重更新极小著称。

两个现象合起来意味着什么

OPD 的学习地形是：只在局部小步移动，而大部分收益来自早期前缀 token。于是问题变成——既然每步预算有限，就该把它花在「教师监督还可信」的前缀上。下一节给出为什么会这样的理论解释。

理论解释

有限预算分配视角：信赖域受限优化

既然实验表明 OPD 只能把学生分布挪动一小段，作者就把真实的 OPD 训练建模成一个受限优化问题：在「离原学生分布不超过 ρ」的信赖域内，尽量靠近教师。

minq  DKL(q ‖ πT)    s.t.    DKL(q ‖ πθ) ≤ ρ Eq.7

这里 ρ 是「有效局部更新预算」（信赖域半径）。这个问题有闭式解（命题 1）：

q★(y) = ( πθ(y) / Zα ) · ( πT(y) / πθ(y) )α    α ∈ (0,1) Eq.8

最优策略 = 在学生策略上，按似然比 r(y)=πT(y)/πθ(y) 重新加权。这一步是全文的「钥匙」：它直接解释了位置偏差为什么会出现。

为什么似然比会随位置下降

沿着学生的 rollout 往后走：前缀在学生下的概率 πθ(y<t) 平滑下降（毕竟样本就是学生采的）；但同一前缀在教师下的概率 πT(y<t) 一旦早期决策偏离教师偏好的推理路径，就会掉得快得多。 于是前缀比值 rtα 在后段越来越小 → 最优策略自然给后段、低比值的前缀及其 token 分配更小的权重。位置偏差，正是这个「比值加权结构」的体现。

▸ 命题 1 的推导骨架（信赖域 → 闭式最优策略） · 拉格朗日 + KKT，得到学生与教师的几何插值

把信赖域约束写进拉格朗日量，对 q(y) 求变分并置零，整理可得：

(1+λ) log q(y) = log πT(y) + λ log πθ(y) + const

令 α = 1/(1+λ) ∈ (0,1)，指数化并归一化，得到学生与教师的几何插值：

qα(y) = πθ(y)1−α πT(y)α / Zα = πθ(y) · rθ(y)α / Zα

α 由半径 ρ 隐式决定：ρ 越大 → α 越大 → 越靠近教师；当预算足够大到教师可行时 α=1，q★=πT，退化回普通蒸馏。（完整证明见原文 Appendix A.1）

本文方法

IW-OPD：把梯度预算花在刀刃上

既然 OPD 能达到的最优只是 q★（按似然比重加权的学生），那不如直接优化 q★ 与教师的散度，让目标天然偏向高概率（教师兼容）的样本：

Jq★ = maxθ  −DKL(q★θ ‖ πT) Eq.9

由于 q★ 是学生与教师诱导出的重参数化分布，可以用「换测度」把它改写成仍从学生 πθ 采样的形式（命题 2）。结果非常优雅：它就是每个 token 的 KL 项乘上一个前缀重要性权重的 OPD：

J★IW(θ) = maxθ  −Ey∼πθ ∑t sg[ r̃t ] · log( πθ(yt|y<t) / πT(yt|y<t) ) Eq.11
其中   r̃t = rt / Zα,t ,   rt = πT(y<t) / πθ(y<t)   （前缀似然比，sg=stop-gradient）

写成策略梯度，就是在标准 OPD 的优势上乘一个脱离梯度的乘法权重：

AtIW-OPD = sg[ r̃t ] · AtOPD Eq.13
两个关键性质
  • 零额外成本：权重只用到 OPD 本来就要算的师生对数概率，不需要任何额外的教师调用。
  • OPD 的超集：去掉权重（r̃t≡1）就退化回标准 OPD。它只是「重新分配」已有的监督信号。

举个具体例子：同一条轨迹，两种「学法」

假设学生解一道题，生成了一条 6-token 的短推理：开头还在正轨上，到第 4 个 token 算错、之后越走越偏。教师在每个位置给出的 OPD 优势 AOPD = log πT − log πθ（多为负）如下——注意从第 4 个 token 起，师生分歧 |A| 明显变大，正是「漂移」开始的地方。

让方法真正能用

稳定权重：从「理想比值」到「可训练权重」

理想权重 r̃t ∝ πT(y<t)/πθ(y<t) 是连乘，随序列变长会剧烈波动，直接用会让训练崩掉。作者用四个递进的技巧把它「驯服」成一个稳定、单调、可控的权重。下面的交互直接用一段固定的 token 优势序列，演示每一步如何改变每个 token 的权重。

交互：四步把「理想比值」变成 IW-OPD 权重

柱子 = 每个 token 位置（左→右）拿到的权重。点不同阶段，看权重形状如何被一步步「稳定化」。

插值强度 γ = 0.5 γ 越大，越偏向教师权重；论文默认 0.5

四个稳定化技巧（对应 Eq.14–17）

技巧 I · 对数缩放

把连乘变成累加

在对数空间处理比值，保序的同时缓解指数累积的爆炸。它恰好等于逐 token OPD 优势的累计和：

r̃logt = α ∑k<t AkOPD
技巧 II · 取绝对值

消除「符号抵消」

个别 token 教师概率高于学生（A 为正），会抵消累计的负差，让漂移的前缀「看起来仍兼容」。改用非负差异，每次分歧都计入：

r̃abst = −∑k<t |AkOPD|
技巧 III · 归一化

跨样本对齐尺度

不同样本的绝对尺度差异大，做样本内标准化，把权重映射到 [0,1]（开头=1，结尾=0）：

r̃normt = 1 − ( ∑k<t|Ak| / ∑k<T|Ak| )
技巧 IV · 与 OPD 插值

额外预算，而非取代

归一化后结尾权重过低，与原始 OPD 插值，保留稠密监督作底座，只额外给兼容前缀加预算：

r̃IW-OPDt = 1 + γ( 1 − ∑k<t|Ak| / ∑k<T|Ak| )

讨论 & 局限

位置偏差不只属于 OPD

「有效的在线监督，不仅要看 token 级的分歧，还要看这个分歧发生在哪段前缀。」

本文的核心洞见是：沿着学生生成的轨迹，教师监督并非处处可靠，开头往往比结尾更有用。这种偏差不是 OPD 独有——任何涉及「从当前策略采样、却朝新策略更新」的两个自回归序列模型的方法（如 on-policy RL）都可能存在。OPD 尤其明显，因为师生分布差事先未知，无法预先划定哪段轨迹仍兼容。

局限（原文 Appendix E）
  • 收敛时 r̃t 趋近 1 − t/T，而非完全均匀——存在轻微的残余非均匀性。
  • 累计前缀差异是一个保守的兼容性代理，并非精确的密度比修正。
  • 实验主要在 4B 学生规模，更大规模的验证留待未来。

与相关工作的关系：IW-OPD 延续「token 选择式蒸馏」（按频率/难度/教师置信度/学生状态加权）的思路，但用在线前缀兼容性作为加权信号；其受限投影视角也连接到信赖域/近端策略更新、GSPO 等序列级重要性修正。它还与奖励设计正交——叠加在 ExOPD 上得到 IW-ExOPD 仍有提升。
